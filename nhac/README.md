# Nhạc

Đặt tệp MP3 trong thư mục này, sau đó sửa `audioUrl` trong `index.html`:

```js
audioUrl: "./nhac/bai-hat.mp3",
```

Đặt tên tệp viết thường, không dấu và dùng dấu gạch ngang thay khoảng trắng để
đường dẫn hoạt động ổn định trên GitHub Pages. Để `audioUrl` là chuỗi rỗng nếu
muốn dùng giai điệu Music Box có sẵn.
